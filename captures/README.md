Real `postman collection run` output (Postman CLI 1.76.0), captured with `PORT=3100 ./capture.sh <file>`.
The service ran on port 3100 (with `--env-var baseUrl=http://localhost:3100`) because port 3000 was occupied on the capture machine; re-run on 3000 if you want URLs to read `localhost:3000`.
Each file is the output of the branch named in the file name; `main-pass.txt` is the passing baseline.
